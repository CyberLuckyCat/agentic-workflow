# 职责

强制约束Agent行为，执行追溯链条检查。

检查当前的，所处的状态阶段内的步骤是否全部正确完成（完成规则需要制定，因地制宜）。

若完成，则允许通过，进度下一阶段。

若未完成，阻止阶段切换，并提示缺少的步骤给出具体修复建议。

门禁阶段状态："需求描述 -> 设计方案 -> 代码实现-> 代码测试"。

状态阶段存在于：（特定项目的状态文件），如若完成则允许进行到需求的下一个阶段处理。
