# 职责

通过feature分支切换，做不同需求的记录与进度管理。

切换分支时，可通过 **requirement-session-restorer 命令，快速将需求进度以及相关的上下文内容，恢复当前工作区的对话上下文内。**

# 结构与三层记忆

├── AGENTS.md			← AI的Persona，指导大模型怎么做。

长期记忆（容量无限，按需检索）（长期存在的骨架，各分支之间共享）
├── context/     			← 知识库：团队规范、项目知识、经验文档
├── skills/      			← 能力封装：可复用的专业技能（根据平台不同，可以迁移到不同目录）
├── commands/      		← 指令封装：常用指令集、流程封装（根据平台不同，可以迁移到不同目录）

溢出区（会话中断时的"存档/读档"）（跟随git需求分支的切换而切换）

└── requirements/ 		← 历史资产：已完成需求的全部产出物
		├──
            		process.txt		← 做到哪了、遇到了什么阻塞
		├──
            		notes.md		← 过程中发现的经验、待沉淀的知识
		└──
            		plan.md		← 当前计划和决策记录

工作记忆（容量有限，需要精细管理）（切换git需求分支后，通过命令还原）
└── 运行时的对话上下文
