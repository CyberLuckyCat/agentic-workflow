# 优化文档

使用 `/knowledge-optimize-doc` 命令优化已有文档的结构和可读性。

## 执行步骤

1. **分析现有文档**：

   - 读取目标文档内容
   - 评估当前的结构和可读性
   - 识别需要改进的问题
2. **优化结构**：

   - 重新组织章节层次
   - 调整标题层级和顺序
   - 改善内容的逻辑 Flow
3. **提升可读性**：

   - 简化复杂的句子和段落
   - 添加适当的过渡和连接
   - 使用清晰的格式和排版
4. **输出结果**：

   - 保存优化后的文档
   - 保持原始内容的完整性
   - 标记修改版本
