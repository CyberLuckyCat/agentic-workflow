# 生成标准操作流程

使用 `/knowledge-generate-sop` 命令从实践数据中生成标准操作流程。

## 执行步骤

1. **分析实践数据**：
   - 收集相关的操作记录和执行步骤
   - 识别成功案例中的关键操作环节
   - 提取标准化的操作模式

2. **设计流程结构**：
   - 定义流程的输入、输出
   - 划分操作阶段和步骤
   - 确定每个步骤的执行要点

3. **编写SOP文档**：
   - 使用标准化的模板格式
   - 包含步骤说明、注意事项、验收标准
   - 添加示例和参考信息

4. **审核和发布**：
   - 校验流程的完整性和准确性
   - 发布到知识库指定位置
   - 标记版本和适用范围
