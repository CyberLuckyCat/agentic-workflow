# 职责

claude code中skill市场的Ralph Loop占位。

核心在于：将同一个Prompt反复输入给Agent，让Agent在文件系统中看到上一轮的成功或进度，从而自主迭代改进。

执行步骤：

1、单轮Agent执行任务（对应7.开发实施阶段，进行编码/配置/测试），并在任务完成后准备退出对话。

2、准备退出对话前，触发Stop Hook，检查完成条件（如： 1、是否正确完成单元测试，输出 `<promise>测试状态通过</promise>`。2、是否达到最大迭代次数。3、相关的文件是否正确更新完毕，状态同步完毕？如：requirement/state.json中的文件状态）。

3、若完成条件不满足，阻止任务完成，把原始Prompt再次输入给Agent，执行步骤1。

4、若完成条件满足，则允许退出。
