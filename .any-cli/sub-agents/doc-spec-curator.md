# SUBAGENTS

同文章中的"engineering-spec-curator"，改名为doc-spec-curator感觉更符合用途与归类。

作用：规范维护。

用户输入/note命令后，由主Agent触发或定时执行。


根据用户输入，有选择的从doc-spec-retriever中获取规范内容，并基于规则步骤进行操作。


规则步骤：

1、如果是定时执行触发，判断文件修改日期后，提示用户是否进行下一步操作。

2、如果是/note命令触发，判断是否与当前需求高度相关。

3、若与当前需求无关，提示用户并让用户重新输入，并明确给出与当前需求相关的地方和原因，并重复步骤2。若与当前需求相关，进行步骤4。

4、若为重复相似规范或者与原有规范产生冲突，提示用户原因，给出决策建议并询问修改方向。否则，进行步骤6。

5、用户输入修改后，进行步骤4。

6、若当判断为是新加入的规范，且与当前的需求高度相关，则调度doc-batch-updater。


# 规范

为主Agent隔离工作区上下文，返回到主Agent工作区上下文中的内容，必须 < 2000 token。

Subagent之间禁止嵌套调用，仅由主Agent协调选择调用。
