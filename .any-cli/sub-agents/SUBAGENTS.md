# 规范

Subagent分为五种类型 --- 不同类型的任务推荐使用不同的模型：

1、初始化类（创建资源，低成本模型）

2、准备类（收集信息）

3、评审类（评估质量，高能力模型）

4、执行类（生成代码）

5、维护类（更新markdown文档）


# 职责

若该Subagent本身的描述信息，与对话上下文中的Agent所需功能匹配，则由大模型按需要自动路由调用Subagent，根据描述信息开始执行任务。

# 描述

当一个任务会产生大量内容输出（长上下文）、需要多轮探索（Ralph Loop）、需要调用专门的知识技能时，它应该独立于主对话Agent，开辟自己的上下文空间变为一个Subagent。
