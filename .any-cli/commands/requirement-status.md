# 查看状态

使用 `/requirement:status` 命令来查看当前需求的状态。

## 执行步骤

1. **定位当前需求**：

   - 检查 `context/` 目录下的活跃需求
   - 获取当前工作的需求信息
2. **读取状态信息**：

   - 获取当前阶段
   - 获取完成百分比
   - 获取待办任务列表
3. **显示状态**：

   - 展示当前阶段的详细信息
   - 列出已完成的任务
   - 列出待完成的任务
4. **返回结果**：

   - 告诉用户当前需求状态
   - 提供下一步建议
