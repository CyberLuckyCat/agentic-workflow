# 下一阶段

使用 `/requirement:next` 命令来进入需求的下一阶段。

## 执行步骤

1. **确认当前阶段**：

   - 读取需求当前状态文件
   - 确认当前所在阶段
2. **执行门禁检查**：

   - 运行当前阶段的门禁检查
   - 验证前置条件是否满足
3. **进入下一阶段**：

   - 如果门禁通过，更新需求状态
   - 记录进入新阶段的时间
4. **返回结果**：

   - 告诉用户阶段转换结果
   - 显示新阶段的门禁要求
