# 职责

工具输出过长时，写入文件，调用该Skill（或plugin）按需读取（长响应时，转文件）

刨根问底！对每条关键信息都要能够准确追溯到来源，且写入需求文档的每一条信息，都必须属于以下三种信息状态之一：

|    信息状态    |             处理方式             |
| :------------: | :-------------------------------: |
|  有项目内引用  |     直接引用（`文件:行号`）     |
| 无引用但可确认 |       标记 `[待用户确认]`       |
|  完全无法确认  | 标记 `[待补充]`+ 列入待澄清清单 |

禁止直接猜测一个逻辑上合理的"答案或解释"后写入文档！

当遇到不确定信息、未能对信息溯源时，直接要求用户给出明确的假设（假设内容、假设依据、假设风险、验证时机等）或提供明确的来源（要通过一个Skill或其他机制去判断来源是否属于项目内？还是这部分可以抹除掉？）后，才允许写入文档。
