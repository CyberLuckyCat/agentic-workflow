# 规范

本md文件，上下文指令必须 < 2k token，内部只能包含对代码、资源文件的链接，不允许深层嵌套。

资源文件已经拆分到res/scripts（代码块）与res/refs（模板与参考资料）中。

skills/skillnamefold 作为一个完整的知识包。
