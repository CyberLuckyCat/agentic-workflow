# 整理知识库索引

使用 `/knowledge-organize-index` 命令整理项目知识库目录结构和索引。

## 执行步骤

1. **扫描当前结构**：
   - 扫描知识库目录
   - 识别现有文件和分类
   - 分析当前的组织方式

2. **规划优化方案**：
   - 评估现有结构的合理性
   - 设计更优的分类体系
   - 确定需要调整的内容

3. **执行整理**：
   - 创建必要的目录结构
   - 移动和重组文件
   - 更新文件引用关系

4. **生成索引**：
   - 创建或更新索引文件
   - 记录目录结构和导航信息
   - 保持索引的可用性
