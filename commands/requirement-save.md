# 保存进度

使用 `/requirement:save` 命令来保存当前工作进度。

## 执行步骤

1. **收集当前状态**：
   - 获取需求当前阶段
   - 获取已完成的任务列表
   - 获取待办事项

2. **保存上下文**：
   - 在 `context/` 目录下创建或更新保存文件
   - 记录当前工作的详细信息

3. **记录检查点**：
   - 保存当前代码状态
   - 保存文档进度

4. **返回结果**：
   - 告诉用户进度已保存
   - 提供保存位置信息
