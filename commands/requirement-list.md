# 查看所有需求

使用 `/requirement:list` 命令来查看所有需求的状态概览。

## 执行步骤

1. **扫描需求目录**：
   - 扫描 `requirements/` 目录下的所有需求
   - 读取每个需求的状态文件

2. **汇总状态信息**：
   - 统计各阶段的需求数量
   - 列出每个需求的名字和当前阶段

3. **展示概览**：
   - 以表格或列表形式展示所有需求
   - 显示每个需求的状态、完成度、当前阶段

4. **返回结果**：
   - 告诉用户需求总数和分布情况
   - 提供快速导航信息
