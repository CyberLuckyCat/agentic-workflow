# 提取可迁移经验

使用 `/knowledge-extract-experience` 命令从实践数据中提取可迁移的经验。

## 执行步骤

1. **收集实践数据**：
   - 识别相关的实践记录、案例、复盘文档
   - 提取关键信息：背景、做法、效果

2. **提炼经验模式**：
   - 分析成功和失败的因素
   - 识别可复用的做法和决策依据
   - 抽象出可迁移的原则

3. **格式化输出**：
   - 结构化描述经验内容
   - 明确适用场景和边界条件
   - 提供实施建议

4. **保存结果**：
   - 输出到知识库或指定位置
   - 标记为可复用资产
