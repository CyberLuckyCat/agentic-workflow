# 回退阶段

使用 `/requirement:rollback` 命令来回退需求的阶段。

## 执行步骤

1. **确认当前阶段**：
   - 读取需求当前状态
   - 确认当前所在阶段

2. **分析影响范围**：
   - 列出回退将影响的内容
   - 列出需要重新执行的任务
   - 评估代码变更的影响

3. **执行回退**：
   - 更新需求状态到前一阶段
   - 记录回退原因

4. **返回结果**：
   - 告诉用户回退结果
   - 列出需要重新完成的任务
