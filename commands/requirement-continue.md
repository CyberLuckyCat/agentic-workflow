# 继续需求

使用 `/requirement:continue` 命令来恢复之前的工作上下文。

## 执行步骤

1. **检查保存的上下文**：
   - 查找 `context/` 目录下的保存文件
   - 读取保存的上下文状态

2. **恢复工作环境**：
   - 读取需求当前状态
   - 恢复上次的进度和位置

3. **加载上下文信息**：
   - 获取需求名称
   - 获取当前阶段
   - 获取未完成的任务

4. **返回结果**：
   - 告诉用户已恢复工作上下文
   - 显示当前所在阶段和待办事项
