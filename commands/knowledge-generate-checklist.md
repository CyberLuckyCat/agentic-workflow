# 生成检查清单

使用 `/knowledge-generate-checklist` 命令从实践数据中生成检查清单。

## 执行步骤

1. **收集检查要点**：
   - 分析实践数据中的关键检查点
   - 识别容易出错的环节
   - 提取需要确认的事项

2. **分类和组织检查项**：
   - 按类别分组相关检查项
   - 确定检查项的优先级
   - 设置必检项和可选项

3. **编写清单内容**：
   - 使用清晰的检查项描述
   - 添加检查标准和方法说明
   - 包含异常情况的处理提示

4. **发布和应用**：
   - 保存为可用的清单格式
   - 标记适用范围和使用场景
   - 定期更新完善
